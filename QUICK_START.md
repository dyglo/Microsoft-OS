# Windows 11 Clone - Quick Start Guide

Welcome to the Windows 11 web-based clone! This guide will help you explore all the new features added in Phase 2.

## Getting Started

1. **Open the Application**
   - The app loads with a desktop view, taskbar at the bottom, and Start menu
   - Desktop shows various application icons

2. **Opening Applications**
   - Double-click any desktop icon to launch an app
   - Apps open in draggable, resizable windows
   - Windows can be minimized, maximized, or closed

## New System Applications

### Notepad
**Location:** Desktop icon (📝)

**Features:**
- Create and edit text files
- **File Menu:** New, Open, Save, Save As, Exit
- **Edit Menu:** Cut, Copy, Paste, Find, Replace
- **Format Menu:** Change font size, enable/disable word wrap
- **Keyboard Shortcuts:**
  - Ctrl+S: Save current file
  - Ctrl+H: Open Find dialog
- **Status Bar:** Shows line count and file size

**Try This:**
1. Open Notepad
2. Type some text
3. Press Ctrl+S to save as .txt file
4. Use Find & Replace to locate text

---

### Calculator
**Location:** Desktop icon (🧮)

**Features:**
- Standard calculator with basic operations (+, -, ×, ÷, %)
- **Scientific Mode:** Switch to advanced functions
  - Trigonometry: sin, cos, tan
  - Logarithms: log, ln
  - Power: x^y, √x
  - Reciprocal: 1/x
  - Constants: π
- **Memory Functions:** MC (clear), MR (recall), M+ (add), M- (subtract)
- **16-digit Display:** Precision calculations

**Try This:**
1. Open Calculator
2. Try: 2 + 3 × 4 = (displays 14, not 20)
3. Click "Scientific" to access advanced functions
4. Calculate sin(45°) or log(100)
5. Use memory functions for complex calculations

---

### Paint
**Location:** Desktop icon (🎨)

**Features:**
- Full drawing canvas with multiple tools
- **Drawing Tools:**
  - Pencil: Sharp, precise lines
  - Brush: Soft, artistic strokes
  - Eraser: Remove content
  - Line: Straight lines
  - Rectangle: Draw rectangles
  - Circle: Draw circles
  - Fill: Fill areas with color
- **Color Picker:** Click to choose any color
- **Brush Size:** Adjust 1-50 pixels
- **Undo:** Revert last stroke
- **Clear Canvas:** Start fresh
- **Save:** Export as PNG/JPG

**Try This:**
1. Open Paint
2. Choose a color from the color picker
3. Select the Brush tool
4. Draw something
5. Click "Save" to download your drawing
6. Use Undo if you make mistakes

---

### Task Manager
**Location:** Desktop icon (📋)

**Features:**
- **Processes Tab:** View running applications
  - CPU usage (%)
  - Memory usage (MB)
  - Current status
  - Sort by CPU, Memory, or Name
  - End Task button to close apps
  
- **Performance Tab:** System metrics
  - Real-time CPU graph
  - Memory, Disk, Network usage
  - Live updating every second
  
- **Startup Tab:** Applications that auto-start
  - Enable/disable startup apps
  - View startup status

**Try This:**
1. Open Task Manager
2. Switch to Performance tab
3. Watch real-time graphs update
4. Go to Processes tab and sort by Memory
5. See mock system processes and your open apps

---

### Recycle Bin
**Location:** Desktop icon (🗑️)

**Features:**
- View all deleted files and folders
- Shows deletion date and original location
- **Restore:** Recover deleted items
- **Delete Permanently:** Remove forever with confirmation
- **Empty Recycle Bin:** Clear all deleted items
- Bulk operations with checkboxes

**Try This:**
1. Create files in File Explorer (see below)
2. Delete some files
3. Open Recycle Bin to see deleted items
4. Restore files you deleted by mistake
5. Empty the Recycle Bin when done

---

## File Explorer with File Operations

**Location:** Desktop icon (📁) or File Explorer app

**Features:**
- **Create:** Make new folders and files
- **Rename:** Edit file/folder names inline
- **Copy/Cut/Paste:** Full clipboard operations
- **Delete:** Move items to Recycle Bin
- **Context Menu:** Right-click for options
- **Breadcrumb Navigation:** See your location
- **Search:** Find files by name
- **Sort:** Organize by name, type, date, size

**Try This:**
1. Open File Explorer
2. Click "New Folder" to create a folder
3. Click "New File" to create a file
4. Right-click files to rename, copy, delete
5. Test paste operations between folders
6. Delete files and restore from Recycle Bin

## Settings - Complete System Configuration

**Location:** Settings app from Start Menu or taskbar

### Settings Pages Available

1. **System**
   - Device name and specifications
   - Processor, RAM, system type
   - Windows edition and version
   - Storage usage with visual bars for each drive

2. **Network & Internet**
   - WiFi status and available networks
   - Bluetooth connectivity
   - Network settings (IP, DNS, gateway)
   - Data usage tracking

3. **Apps**
   - Installed applications list
   - Default apps (browser, email)
   - Startup applications
   - Enable/disable and remove apps

4. **Accounts**
   - User profile with avatar
   - Change password securely
   - PIN setup for quick access
   - Multiple sign-in options
   - Add new user accounts

5. **Time & Language**
   - Automatic time synchronization
   - Timezone selection
   - Display language (9+ languages)
   - Keyboard layout configuration
   - Regional format examples
   - Speech language settings

6. **Accessibility**
   - High contrast mode
   - Text size adjustment (80-200%) with live preview
   - Cursor and pointer size
   - Narrator with voice selection
   - Keyboard and mouse customization
   - Magnifier settings

7. **Windows Update**
   - Check for updates
   - Update status display
   - Update progress visualization
   - Update history
   - Automatic update settings
   - Delivery optimization

**Try This:**
1. Open Settings from Start Menu
2. Click "System" to see device info
3. Go to "Accessibility" and adjust text size
4. Check "Time & Language" to change timezone
5. View "Windows Update" status

## Tips & Tricks

### Productivity
- **Notepad:** Great for quick notes, supports find & replace
- **Calculator:** Switch between Standard and Scientific modes
- **Settings:** Explore all pages to understand system options

### File Management
- Files are virtually stored (no real disk access)
- Deleted files go to Recycle Bin (can be restored)
- All operations are saved to browser storage

### System Apps
- Each app opens in its own window
- Windows are draggable and resizable
- Close buttons (X) or minimize (/−) any window
- All changes persist on page reload

## Common Tasks

## Troubleshooting

### App Won't Open
- Double-click the desktop icon
- Check browser console for errors
- Reload the page if needed

### Changes Not Saving
- Browser storage may be disabled
- Check browser privacy settings
- Try a different browser

### Performance Issues
- Close some open windows
- Refresh the page
- Try a modern browser (Chrome, Edge, Firefox)
